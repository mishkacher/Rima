# Спутник — единый сайт

Один цельный сайт, собранный из контента и визуальных материалов проекта Figma `RIMA — Editorial Motion`.

## Состав

- `index.html` — семантическая разметка;
- `style.css` — 12-колоночная редакционная система и адаптив;
- `orbit-motion.css` — движение орбитальной системы и спутников;
- `app.js` — меню, раскрытие тарифов, навигация, интерактив кейса и форма;
- изображения берутся из сохранённого в этом же репозитории Figma-экспорта;
- заголовочная кириллическая гарнитура встроена в CSS.

Сайт не использует внешние библиотеки, CDN или изображения-заглушки.
