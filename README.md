# RIMA — five redesign concepts

Пять рабочих направлений редизайна сайта дизайн-студии RIMA, собранных на одной адаптивной странице для удобного сравнения и презентации заказчику.

Исходный публичный сайт: https://xn--h1aehhjhg.agency/

## Концепции

- **A · Editorial** — светлая premium/editorial подача, крупная типографика и мягкая орбитальная метафора.
- **B · Cosmos** — тёмная digital-система с космической глубиной, свечением и технологичной типографикой.
- **C · Brutal** — контрастный creative/brutalist вариант с жёсткой сеткой, рамками и выразительной палитрой.
- **D · Luxe** — тёплая премиальная editorial-система с serif-типографикой, мягкими формами и бордовым акцентом.
- **E · Swiss** — строгая швейцарская сетка, монохром, красный акцент и функциональная типографика.

Переключатель концепций закреплён в нижней части экрана. Выбор сохраняется локально и записывается в URL, поэтому любой вариант можно отправлять отдельной ссылкой:

- `?concept=editorial`
- `?concept=cosmos`
- `?concept=brutal`
- `?concept=luxe`
- `?concept=swiss`

## UX действий

Во всех пяти вариантах используется одинаковая понятная логика действий, при этом визуальный характер кнопок адаптируется под дизайн-систему конкретного концепта:

- главный CTA **«Обсудить проект»** доступен в шапке и первом экране;
- на мобильном CTA находится внутри компактного меню;
- второе действие hero — **«Смотреть кейсы»**;
- **«Все проекты»** — отдельная кнопка в секции работ и ведёт на Behance-профиль студии;
- карточки опубликованных кейсов кликабельны целиком;
- CTA тарифов ведут к контактному блоку без лишнего перехода со страницы;
- sticky-header и scroll-offset не перекрывают заголовки секций;
- интерактивные элементы имеют удобные tap-target, focus и hover states.

## Что сохранено из исходного сайта

Hero, позиционирование студии, команда, шесть кейсов, форматы работы `Старт / Орбита / Галактика` и финальный CTA. Для опубликованных кейсов проставлены реальные ссылки на Behance.

Реализация не копирует Tilda-generated markup: проект собран заново на семантических HTML/CSS/JS-компонентах.

## Качество

GitHub Actions запускает два уровня проверки:

1. **Static QA** — структура, пять концептов, CTA/navigation contracts, accessibility states и deployment config.
2. **Browser QA** — каждый из пяти вариантов реально открывается в Chromium на desktop `1440×1000` и mobile `390×844`.

Browser QA проверяет активный concept state, видимость ключевых CTA, мобильное меню и Escape-close, destination кнопки «Все проекты», отсутствие JS page errors и горизонтального overflow. После успешного прогона сохраняются 10 full-page screenshots в artifact `rima-five-concepts`.

## Клиентские assets

В концептах используются собственные CSS-композиции вместо копирования изображений из Tilda/Behance. Это позволяет сравнить визуальные направления независимо от качества исходных изображений. После выбора финального направления оригинальные фотографии и клиентские assets можно подключить без перестройки сетки и дизайн-системы.
