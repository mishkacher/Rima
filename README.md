# Rima — redesign concepts

Независимый редизайн сайта дизайн-студии Rima.

Референс / исходный публичный сайт: https://xn--h1aehhjhg.agency/

## Концепции

- **A · Editorial** — светлая premium/editorial подача, крупная типографика и мягкая орбитальная метафора.
- **B · Cosmos** — тёмная digital-система с космической глубиной, свечением и технологичной типографикой.
- **C · Brutal** — контрастный creative/brutalist вариант с жёсткой сеткой, рамками и выразительной палитрой.

Переключатель концепций закреплён в нижней части экрана. Выбранный режим запоминается в `localStorage`.

## Структура

Содержательно сохранены ключевые блоки исходного сайта: hero, о студии, команда, кейсы, форматы работы `Старт / Орбита / Галактика`, CTA.

Реализация не копирует Tilda-generated markup: проект собран с нуля на семантических HTML/CSS/JS-компонентах.

## Preview

Проект статический. Для локального просмотра достаточно открыть `index.html` или запустить любой static server, например:

```bash
python3 -m http.server 8080
```

После этого открыть `http://localhost:8080`.

## Текущее состояние

Первая концептуальная итерация использует авторские CSS-иллюстрации вместо оригинальных клиентских изображений. На следующем этапе их можно заменить на реальные ассеты/фото из исходного проекта или экспорт Tilda без изменения дизайн-систем.
