# RIMA — redesign concepts

Независимый редизайн сайта дизайн-студии RIMA.

Исходный публичный сайт: https://xn--h1aehhjhg.agency/

## Концепции

- **A · Editorial** — светлая premium/editorial подача, крупная типографика и мягкая орбитальная метафора.
- **B · Cosmos** — тёмная digital-система с космической глубиной, свечением и технологичной типографикой.
- **C · Brutal** — контрастный creative/brutalist вариант с жёсткой сеткой, рамками и выразительной палитрой.

Переключатель концепций закреплён в нижней части экрана. Выбор сохраняется локально и записывается в URL, поэтому любой вариант можно отправлять отдельной ссылкой: `?concept=editorial`, `?concept=cosmos`, `?concept=brutal`.

## Что сохранено из исходного сайта

Hero, позиционирование студии, команда, шесть кейсов, форматы работы `Старт / Орбита / Галактика` и финальный CTA. Для опубликованных кейсов проставлены реальные ссылки на Behance.

Реализация не копирует Tilda-generated markup: проект собран заново на семантических HTML/CSS/JS-компонентах.

## Качество

- desktop + mobile responsive layout;
- мобильная навигация;
- keyboard focus states;
- skip-link;
- `aria-expanded` / `aria-pressed` состояния;
- `prefers-reduced-motion`;
- shareable concept URL;
- автоматический static smoke audit в GitHub Actions.

## Локальный preview

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080/`.

## Клиентские assets

В концептах намеренно используются собственные CSS-композиции вместо копирования изображений из Tilda/Behance. Это позволяет безопасно выбрать визуальное направление до переноса оригинальных клиентских исходников. После выбора концепта реальные изображения и фотографии можно заменить без перестройки сетки и дизайн-системы.
